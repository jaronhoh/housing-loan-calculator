# 08 - 需求模块清单（Excel 驱动评审稿 v0.2）

> 2026-10-25。此文件是 PM 阶段的**完整模块需求草案**，供 GitHub 审查；不是已冻结 PRD，也不表示 8,064 个公式已经通过数值验证。所有标为「源表规则」的行为来自 Property Calculation v2.xlsx 的先前工作簿分析；字段与精度须以逐格映射复核。

## 决策和通用验收

- DEC-001：完整 Property Investment & Mortgage Calculator，非仅房贷。
- DEC-002：严格复现 Excel 的公式、条件、跨表引用、计算精度与结果；任何改进须另列变更并取得同意。
- DEC-003：用独立 Markdown + ASCII 线框图进行 UI 审查。
- 计算字段只读；输入字段应在 UI 显示来源、单位、允许值和依赖输出。**输入/输出身份仍以最终单元格映射为准**。
- 每个模块至少有：普通案例、零/空值、边界值、不同情景、原 Excel 缓存值对照；差异不得默默修正。
- 金额 RM、百分比、月/年及 sqft 在 UI 明示。显示格式不等于计算时的舍入。

## 主要计算链

```text
Property + Net Price + Bank Value + Loan Assumptions
                |
                +--> Loan / PMT / Interest / Principal
                +--> Purchase Fees --> Initial Cash Out <-- Renovation
                |
Whole Unit Rent + Room Rent --> MAX(Net Rent) <-- Other Investment
                                    |
Operating Expenses + Loan Payment --+--> Cash Flow / ROI
                                    |
Loan Balance + Appreciation --------+--> Monthly Schedule
                                           |
                                       Sale 90% / 60%
                                           |
                                     RPGT / Profit / Export
```

## 必须显式记录的源表特殊行为

1. 房屋出租收益是 Whole Unit 与 Room Rental **净收益最大值**；UI 不能仅凭一个 Rental Mode 单选钮改变计算。
2. 原始 ROI = Cash Flow / Total Expense，**不是**通常的年化现金投资回报率。
3. 源表使用 Total Loan Amount 作为若干 Rental Yield 分母。
4. Initial Cash Out 可能为负；不得强制归零。
5. 装修 Other 项与 Need? 的条件关系特殊。
6. 月度 Schedule 是固定 420 行；贷款实际年限和还清后的行为必须测。
7. 源表法定费用、RPGT、税费率仅作为复现基准，不宣称符合 2026 马来西亚法规。
8. 多列房产比较可能包含手工硬编码覆盖，不能盲目批量复制同一公式。
