# Property Investment & Mortgage Calculator

A Malaysia-oriented property investment calculator based on `Property Calculation v2.xlsx`.

## Confirmed decisions
- DEC-001: Full property investment calculator, not mortgage-only.
- DEC-002: Strict Excel compatibility. Formulas, conditions, precision and rounding must match the workbook; apparent errors are documented, not silently changed.
- DEC-003: Keep a standalone ASCII wireframe Markdown document.

## Project stage
Requirements discovery / Excel formula mapping. No production implementation or validated formula parity yet.
